# Audit Specification

## Audit Categories

### 1. Visual UI Auditor

Checks:

* Font consistency
* Button consistency
* Layout alignment
* Spacing consistency
* Card consistency

---

### 2. Responsive Auditor

Viewports:

Desktop:

* 1920x1080
* 1366x768

Tablet:

* 768x1024
* 820x1180

Mobile:

* 390x844
* 375x667
* 412x915

Checks:

* Overflow
* Hidden content
* Horizontal scrolling
* Broken layouts
* CTA visibility

---

### 3. Navigation Auditor

Checks:

* Header navigation
* Footer navigation
* Internal links
* External links
* 404 pages
* Redirect loops

---

### 4. Breadcrumb Auditor

Checks:

* Breadcrumb presence
* Breadcrumb hierarchy
* Breadcrumb links
* Breadcrumb schema

Only when applicable.

---

### 5. Forms Auditor

Checks:

* Form detection
* Submit buttons
* Success messages
* Error messages
* Loading states

Validation only.
No real submissions.

---

### 6. Input Validation Auditor

Checks:

* Required fields
* Email validation
* Phone validation
* Long input handling
* Special character handling

---

### 7. Content Auditor

Checks:

* Missing content
* Empty sections
* Placeholder text
* Spelling issues
* Grammar issues

---

### 8. Images & Media Auditor

Checks:

* Broken images
* Distorted images
* Missing images
* Video playback
* Missing alt text

---

### 9. Typography Auditor

Checks:

* Readability
* Heading hierarchy
* Font sizes
* Contrast

---

### 10. Branding Auditor

Checks:

* Logo presence
* Logo consistency
* Brand color consistency
* CTA consistency

---

### 11. SEO Auditor

Checks:

* Title tags
* Meta descriptions
* H1 structure
* H2 structure
* Alt tags
* Canonical tags
* URL cleanliness

---

### 12. Performance Auditor

Checks:

* Performance score
* LCP
* FCP
* CLS
* TBT
* Heavy assets

---

### 13. Accessibility Auditor

Checks:

* Missing labels
* Missing alt text
* Contrast violations
* Keyboard navigation
* Focus states
* ARIA issues

---

### 14. Security Auditor

Checks:

* HTTPS
* SSL
* Mixed content
* Security headers

---

15. Footer Compliance Auditor

Checks:

Required Footer:

:::| powered by dimakh consultants |:::

Required Link:

https://www.dimakhconsultants.com/

Required Title:

Leading AI-Integrated Digital Agency in Pune, India : Web, Apps & Next-Gen Marketing

Checks:

Footer presence
Required footer text
Required footer link
Correct link destination
Required title attribute
Footer visibility across pages
Footer consistency across scanned pages

16. Technical Auditor

Checks:

Favicon
robots.txt
sitemap.xml
Console errors
Network errors
Working 404 page
17. CTA Auditor

Checks:

CTA visibility
CTA clickability
CTA destination
18. User Journey Auditor

Checks:

Homepage to Contact flow
Homepage to Service flow
Dead-end pages
Broken conversion paths
19. Crawl Integrity Auditor

Checks:

Orphan pages
Dead-end pages
Redirect chains
Broken internal linking
Excessive click depth
Screenshot Policy

Capture screenshots only for:

CRITICAL:

Layout breaks
Hidden CTAs
Broken navigation
Form issues

HIGH:

Font inconsistencies
Alignment issues
Responsive issues

Do not capture screenshots for:

SEO issues
Metadata issues
Spelling mistakes
Audit Limits
Max Pages: 50
Same Domain Only
No Form Submission
Desktop Audit
Mobile Audit
Health Score

Categories contribute to:

SEO
Performance
Accessibility
Responsiveness
Forms
Navigation
Security
Content
Branding

Final score range:

0 - 100
